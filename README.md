# Epochs of Dominion

A real-time strategy game across fifteen epochs, from the Dawn Age to the Nano Age. It has historical campaigns, skirmishes against computer opponents, and save slots. It runs in any modern browser with mouse and keyboard or touch.

**Play:** https://8kr8y697ds-beep.github.io/epochs-of-dominion/

**Install on iPhone:** open the link in Safari, tap Share, then **Add to Home Screen**. It launches full screen and works offline after the first visit.
